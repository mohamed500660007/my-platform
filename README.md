# منصّة بــن نــاجــح

منصّة تعليمية لطلبة **الصف الثاني بكالوريا** — مادة البرمجة والذكاء الاصطناعي.
إعداد وشرح: م. محمد ناجح.

**الموقع:** https://mohamed500660007.github.io/my-platform/

---

## المحتوى

| الملف | الوصف |
|---|---|
| `index.html` | الصفحة الرئيسية للمنصّة |
| `curriculum-map.html` | خريطة المنهج — ٤ وحدات · ١٤ درسًا |
| `lesson-1-1.html` … `lesson-1-4.html` | مذكّرات الوحدة الأولى (كاملة) |
| `questions-1-1.html` · `questions-1-2.html` | بنك الأسئلة بإجابات نموذجية |
| `presentation-1-1.html` | العرض التقديمي للدرس ١-١ |
| `*.pdf` | نسخ PDF للمذكّرات والكتاب المدرسي |
| `design-system.md` | نظام التصميم — الألوان والخطوط والمكوّنات |

## البنية

```
index.html            الهيكل فقط
assets/styles.css     كل الأنماط
assets/app.js         سلوك الواجهة
```

## الأدوات

```bash
npm install           # مرّة واحدة
node audit.mjs        # فحص شامل على ٥ مقاسات شاشة
node shot.mjs 1440 app   # لقطة لقسم معيّن
```

`audit.mjs` بيفحص: أخطاء الكونسول · الطلبات الفاشلة · الصور الناقصة ·
التمرير الأفقي · المسافات الخارجة عن السلّم · النص المزنوق · أهداف اللمس.
